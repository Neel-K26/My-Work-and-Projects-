# Machine Learning Learning Vault 🚀

A comprehensive, notebook-first repository that captures an end-to-end machine learning journey — from **Python fundamentals** to **advanced ML and deep learning concepts**.

This project is designed as a practical learning archive with hands-on experiments, assignments, visualizations, and algorithm implementations across multiple ML domains.

---

## 📚 What this repository is

This repo is a curated collection of Jupyter notebooks (`.ipynb`) and exported HTML practice files that cover:

- Core Python for data/ML
- Data preprocessing and wrangling
- Visualization with Matplotlib/Seaborn
- Supervised learning algorithms
- Unsupervised learning algorithms
- Model evaluation and optimization
- Introductory neural networks and deep learning setup

Think of it as a **self-paced ML curriculum with executable labs**.

## ▶️ How to Run

1. Install Python 3.10+ (recommended)
2. Create and activate a virtual environment
3. Install required libraries:

```bash
pip install jupyter numpy pandas matplotlib seaborn scikit-learn
```

4. Launch Jupyter:

```bash
jupyter notebook
```

5. Open notebooks in learning order (start from foundations and move up)

---

## 💡 Best Practices for Learners

- Run notebook cells from top to bottom to avoid state issues
- Convert absolute local dataset paths to relative paths when needed
- Keep notes of metrics/observations after each model run
- Compare algorithms on the same dataset for deeper intuition
- Re-implement key workflows in standalone `.py` scripts for mastery
